# BIMduo — тренажёр к срезу по BIM

Статический сайт без сборки и сервера: откройте `index.html` в браузере (Chrome, Edge, Firefox).

## Режимы

- **Курс** — уровни по вариантам: соответствия, последовательности, выбор ответа, открытые вопросы, итог варианта.
- **Итоговый срез** — 20 вопросов блоками: 5 соответствий → 5 последовательностей → 5 тестовых → 5 развёрнутых. Отдельно для варианта 1, варианта 2 и смешанный режим.
- **Ответы** — все 80 заданий с эталонными ответами и пояснениями, поиск по тексту.
- **Свободная тренировка** — повторение, случайные 20, все задания, работа над ошибками.

## Итоговый срез

- Наборы не повторяются, пока не исчерпан банк раздела; затем начинается новый цикл, и задания прошлого среза в него не попадают.
- До сдачи не показываются правильные ответы и объяснения.
- Развёрнутые ответы сохраняются и после сдачи сравниваются с эталоном; оценку вы ставите сами по ключевым пунктам.
- Прогресс, XP, ошибки и история наборов хранятся в `localStorage` браузера.

## Проверка ответов

Разбор фактических правок и спорных мест исходника — в `ANSWER_REVIEW.md`.
